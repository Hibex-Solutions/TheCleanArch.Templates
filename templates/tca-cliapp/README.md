# TheCleanArch.Templates.CliApp

Este é um aplicativo de linha de comando de exemplo usando `System.CommandLine`.

O exemplo demonstra como criar comandos, opções e argumentos, e como processar
a entrada do usuário para realizar ações específicas.

O aplicativo em si trabalha com um arquivo de texto que contém citações,
permitindo ler, adicionar e excluir citações com base em termos de pesquisa.
O próprio arquivo é incorporado ao projeto e se chama `sampleQuotes.txt`, e
ele também está marcado em `TheCleanArch.Templates.CliApp.csproj` para ser
copiado junto ao executável na publicação.

Para mais informações sobre como usar `System.CommandLine`, consulte a
documentação oficial:
https://learn.microsoft.com/pt-br/dotnet/standard/commandline/get-started-tutorial
